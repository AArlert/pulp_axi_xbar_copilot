# doc/guards.md — regression guard table (F4)

Single table replacing the 49 `## regression_guard` sections previously
scattered across `doc/bugs/*.md` (design contract
`doc/design-prompt/doc_mechanization.md` §F4, gated by
`doc/review/REV-038.md` §A; migration done under the REV-038 §C batch-2
implementation card). Each detail page's `## regression_guard` section now
holds a one-line pointer into this table (id below); the original prose is
preserved here verbatim (mechanical relocation, not a rewrite — discipline
§3), joined into a single physical line per markdown table-cell syntax.

Schema (`columns_preset=en`): `| id | bugs | type | paths | check | note |`.

- `id`: guard id (`G-xxx`, matches the source bug's own number —
  `G-0049` migrated from `doc/bugs/BUG-0049.md`).
- `bugs`: bug id(s) this guard belongs to (comma-separated for a
  族级/family guard; every row below is a 1:1 migration, so a single id).
- `type`: `script` | `checklist`.
- `paths`: ASCII + glob only, comma/whitespace separated (BUG-0061: CJK
  punctuation broke `docs.py`'s `[,\s]+` split into dead tokens that never
  matched; the 9 pages REV-037 §1 named — BUG-0038/0039/0040/0042/0043/
  0045/0046/0047/0048 — are cleaned here; 3 of the 9 (0043/0045/0047) had
  genuinely *lost* their intended path and are restored to it, the other 6
  keep the token that already worked and drop the decorative CJK suffix).
- `check`: `type: script` rows' executable command (§12 executor); `-` for
  `type: checklist` rows.
- `note`: full original guard-section prose (verbatim, `|` escaped as
  `\|`).

**Migration judgment call (see delivery report for the full reasoning)**:
of the 49 pre-existing guards, exactly **one** (`G-0062`, BUG-0062's
`grep -c always vendor/common_cells/src/lzc.sv`) is a safe, read-only,
non-`make`, non-simulation one-liner that satisfies §12's executor
contract as-is — it is migrated as `type: script`. The other 48 (including
the pages that already declared `type: script`, e.g. BUG-0036/0037/0040/
0048/0063/0064/0066) describe actions that require `make run`/`make
regress`/`xdebug`/non-repo `sim/out/urgText6/` data, or invoke `python3`
outside the §12 A-c1 whitelist (`scripts/docs.py`/`scripts/svacheck.py`
only) — inventing a docsx-safe equivalent for any of them would be
*rewriting* the guard's semantics (forbidden by this card's own boundary:
"不重写任何 guard 的语义"), not migrating it, and §12's `make` denylist is
a deliberate gate (discipline §2), not something to route around. All 48
are `type: checklist`, routed through the F10 baseline as A-c5 exceptions
(`doc/docsx-baseline.md`, family `F4`, rev_ref `REV-038 §A-c5` — two rows,
`G-0057`/`G-0059`, additionally cite their own REV-037 per-bug ruling,
since their source pages already named REV-038 §A-c5 as their exception
channel before this migration existed).
