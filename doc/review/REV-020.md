## 2. 逐条结论（本卡六问 1-6）

### Q1 — 头注释确记重叠为受支持特性？L133 断言确与之冲突（非 DV 转述有误）？

**确认，属实。** (a)(b) 明载重叠 + 高位置胜出为受支持特性；(e) 证 `idx_o` 覆写实现正是该特性的功能落点，且重叠命中时 `matched_rules` **合法**多位置 1；(f)(g) 证 L133 是仅仿真末采样一次的 `final` 断言，其 `$onehot0(matched_rules)` 隐含假设与该文档化特性在"末拍地址停在重叠区"时冲突。这是**vendored RTL 模块自身的内部不一致**（文档化并功能实现了重叠，却又装一条对 `matched_rules` 过强的末态断言），**非 DV 转述失真**。补正：该冲突仅在 `final` 一拍可观测，run 全程 `matched_rules` 多位置 1 **不触发**任何断言（L133 非 concurrent），DV 对"end-of-sim 残留值假象"的刻画准确。

### Q2 — spec 确无条款覆盖此内部调试信号？SPEC_ISSUE 被排除是否成立？

**成立。** `grep` 全文：spec 提"重叠"仅 §3.1.3（L112，与 (a) 同向：允许重叠、高位置胜出），提匹配语义仅 §3.2（L117-119，半开区间 + `start<=end`）。spec **通篇未提** `matched_rules`/`onehot0`/`more_than_1_bit_set`/末态断言。且 (d) 证 `matched_rules` 是内部调试信号、非 DUT 输出端口。故 SPEC_ISSUE 判据（"spec 与上游文档相抵触，或对某行为不定义，且 DUT 与 TB 各在不同读法下都站得住"）**不命中**：(i) spec 对该内部信号**沉默**，但沉默处**无 DUT-vs-TB 的期望值分歧**——scoreboard 与 DUT 对功能行为（路由）完全一致（k：route 60/0）；冲突纯属 vendored RTL **断言 vs 自身文档**的内部矛盾，非 spec 解释之争。(ii) 一次 spec 编辑**解决不了任何东西**（无 spec 治理的行为、无依赖它的 checker 期望值）。DV 排除 SPEC_ISSUE 的推理成立。**结论：pass。**

### Q3 — 收尾腿绕过是否只追加非重叠收尾事务、不掩盖任何本应检出的功能失配？

**属实，不掩盖。** (h)(i) 证收尾腿**只追加**（region 1 单命中）、**不删改**任何重叠腿；SPEC-3.1.3 的 tie-break 由前置 `num_iter` 重叠腿充分激励，且这些重叠腿的路由**仍全部经 scoreboard 判定**（k：match=60 含全部重叠腿 + 收尾腿，mismatch=0）。绕过只改变 `$finish` 那一拍**地址总线残留值**（非功能量），恰对准 L133 这条非功能末态断言的触发条件，**不弱化** M4-OV01 判据面。可证伪性完好：若 DUT 把重叠 tie-break 判反（低位置胜出），(j) 的 spec 派生 refmodel 会立刻报 route mismatch——检查非装饰。**结论：pass。** 附：DV **未**采用 `+define+COMMON_CELLS_ASSERTS_OFF` 或 `disable_assert_final_checks`（二者会静默全库/全未来测试的末态断言——放宽 gate，discipline rule 2 红线），改走 scope 最小的激励侧 hygiene——**这是纪律正确的选择**（见 §3(b)）。

### Q4 — taxonomy 终判

**成本阶梯逐级复核：**
- **TOOL_ENV — 排除**：给定激励确定性触发（末拍地址停重叠区），与 seed/机器/build 无关；不匹配 `vcs-2018.mk` 任何已知 O-2018 traits。

- **SPEC_ISSUE — 排除**：见 Q2。
- **DUT_BUG — 候选，但 bar 未达，不予签核**：taxonomy 的 DUT_BUG 判据是"waveform 显示 **DUT 输出**违反**显式 spec 条款**"。此处 DUT 输出（`idx_o`/`dec_valid_o`/`dec_error_o`）**不违反任何 spec 条款**（k 证功能路由零失配、正确遵循 §3.1.3）；"失败"的是一条**内部调试断言**、非 DUT 输出。按"DUT_BUG requires rev signoff to assert"且"earned by eliminating everything else"——本条 DUT 功能正确性已被 (k) 证成，DUT_BUG bar **未达**，**rev 不予签核 DUT_BUG**。

**终判：DUT_BUG（候选）→ 候选否决，不签 DUT_BUG。终态类别 = WONTFIX（accepted-vendor-quirk）。** 其本质是**benign 的 vendored-RTL 内部不一致**：一条 `final` 块调试断言（对调试专用信号 `matched_rules` 的 onehot0 假设）相对模块自身文档化并已功能实现的 overlap 特性**过强**，仅在末拍地址停重叠区时误触，且被 `svacheck.py` Layer1 正则升格为 FAIL。它既非 DUT_BUG（无功能 spec 违例）、非 TB_BUG（无错误期望值/协议违例）、非 SPEC_ISSUE（无 spec 治理行为、无期望值歧义）。WONTFIX 可与"cost/benefit 说停"的任一底层性质配对（`workflow/bugs.md` 终态对应表），此处底层性质即"sub-DUT_BUG-bar 的 vendored-RTL 调试断言过强"。
