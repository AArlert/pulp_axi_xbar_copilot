# BUG-0063 — §10.2(B) "31 个行号" 与机器来源不符（订正段自身复现 BUG-0051 形状）

## symptom

`doc/evidence/v0.4.35/M4-coverage-final-sweep.md` §10.2(B)（`:491`）称"有 Cond 节
的 11 个模块……其**全部** Cond bin 的源码行（程序化逐行核对，**共 31 个行号**）
无一例外都含 `&&`/`||`/`?:`"。独立复算实为 **57 个不同（模块,行号）对 / 53 个不同
行号**（两种独立提取口径互证）。

**结论本身成立**——57/57 逐条回 RTL 全部含 `&&`/`||`/`?:`，故不阻断关闭；缺陷在于
**声明性数字与其自称的机器来源（`modinfo.txt` 逐行核对）不符**。这是 BUG-0051 (i)
的形状第三次出现，而这次的载体是"为修 BUG-0051 而写的订正段本身"——修复动作在修复
过程中复现了它要修的缺陷类型。族谱：BUG-0049（漏账）→ BUG-0050（超额认领）→
BUG-0051（事实错抄）→ 本条（订正段错抄），四者同根：声明面与事实面之间没有机器核对。

## rerun

非仿真订正。实质复验位置 = `M4-coverage-final-sweep.md` §10.5 `ERRATA-FACTS` 的
E5 两行 + §10.6 的可重放提取命令。正确计数自 `sim/out/urgText6/modinfo.txt` 现场
重算（只读；未 `make clean`、未 `make regress`、未写 `sim/out/`）：

```
python3 - <<'PY'
import re
DUT={"axi_xbar","axi_xbar_unmuxed","addr_decode","addr_decode_dync","axi_demux",
 "axi_demux_simple","axi_demux_id_counters","counter","delta_counter","axi_err_slv",
 "axi_atop_filter","stream_register","axi_mux","axi_id_prepend","rr_arb_tree","lzc",
 "fifo_v3","axi_multicut","axi_cut","spill_register","spill_register_flushable","axi_pkg"}
hdr=re.compile(r'^(\S+) Coverage for Module : (\S+)'); ln=re.compile(r'^\s*LINE\s+(\d+)\b')
metric=mod=None; pairs=set()
for r in open("sim/out/urgText6/modinfo.txt",encoding="utf-8",errors="replace"):
    m=hdr.match(r)
    if m: metric,mod=m.group(1),m.group(2); continue
    if metric=="Cond" and mod in DUT:
        x=ln.match(r)
        if x: pairs.add((mod,int(x.group(1))))
print(len(pairs),"pairs /",len({n for _,n in pairs}),"distinct lines")
PY
```

实测输出：`57 pairs / 53 distinct lines`。分布（不同行号数，和=57）：atop_filter 19,
rr_arb_tree 8, spill_register_flushable 8, demux_simple 4, fifo_v3 4,
demux_id_counters 3, mux 3, addr_decode_dync 2, err_slv 2, xbar_unmuxed 2, lzc 2。
子集互证：spill_register_flushable={53,72,78,79,84,85,90,96}、lzc={76,95} 与
§10.2(B) 括注逐字一致。证伪程序：把 §10.5 的 57 改成 56 → 复算必红；还原 → 复绿。

**Q3 局限（须明写）**：`sim/out/urgText6/modinfo.txt` 在 `.gitignore`（`sim/out/`）内、
不受版本控制，且会被任何 `make regress` 删除（BUG-0056/0066）⇒ 本取数不满足七问 Q3
