# BUG-0056 — `doc/bugs/BUG-0040.md`'s `regression_guard.ref` carried a destructive `make clean` step

## symptom

`doc/bugs/BUG-0040.md`'s (and, until 2026-08-02, `doc/bugs/BUG-0048.md`'s)
`## regression_guard` section read:
`ref: `cd sim && make clean && make lint-diff TEST=<any baseline
TEST>``. `sim/Makefile:187`'s `clean:` target is `rm -rf $(OUT)`, which
deletes all 7 `cov.vdb` coverage databases under `sim/out/` — M4
signoff's coverage-evidence base, `.gitignore`'d, no version-control
backup — for zero benefit to the guard's own stated purpose: `lint-run:`
(which `lint-diff:` depends on) already forces a full recompile itself
(`rm -f $(OUT)/simv_lint.daidir/.vcs.timestamp`) and self-proves per-file
coverage of `../tb/` (the BUG-0022 fix). The `make clean` step
contributed nothing `lint-run:` didn't already guarantee — pure
destructive cost, no corresponding benefit.
