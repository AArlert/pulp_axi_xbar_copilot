# BUG-0059 — 子代理 scratchpad 未按实例隔离

## symptom

子代理 scratchpad 未按实例隔离——同一目录下混放多个角色实例的中间产物，closer
可直接读到 fixer 的推理过程，构成共模隔离的实质漏洞。本会话分配的 scratchpad
`/tmp/claude-1000/<repo>/<session-uuid>/scratchpad/` 被**所有**子代理共用，实测
其中同时存在不同 bug 卡的 fixer 中间产物、arch fixer 的脚本、orch 自己的笔记与
临时文件。CLAUDE.md §0 的隔离要求是"DV 绝不读 DE 的推理过程（卡中只传文件路径、
章节号、行 id）"、"共模误差是大敌"——**卡片传参**这一层做到了防火墙，**文件系统
侧没有**。详见 `doc/bugs.md` BUG-0059 行、`doc/review/REV-037.md` §BUG-0059。
