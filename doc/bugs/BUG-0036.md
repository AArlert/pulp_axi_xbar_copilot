# BUG-0036 — `regress.list` 缺 M3-CFG02（`m3_cfg02_reconfig_test`），全回归分母漏一条 ✅ 场景

## symptom

`sim/regress/regress.list`（M3 签核前 21 行）不含 `m3_cfg02_reconfig_test`，
而 `doc/testplan.md` M3-CFG02 行为 ✅ 场景（repro=`make run
TEST=m3_cfg02_reconfig_test SEED=1`，承载 BUG-0031 `c_bug31_livev1`
活值表守卫）。后果与 BUG-0028 同族（回归分母静默缩水）：`make regress`/
`doc/evidence/v0.3.20/result_summary.txt` 报 21/21 PASS，但覆盖范围不含
CFG02——绿灯看起来完整，实际漏了一条已登记 ✅ 的场景。

更具体的时间线：CFG02 的登记证据 `doc/evidence/v0.3.9/M3-CFG02.log`
（2026-07-29）**早于** BUG-0034 monitor/SVA 重写（commit `d7f5011`，
0.3.18，改 `tb/slvport_agent.sv`/`tb/sva/axi_chan_sva.sv`——正是
CFG02 判据所在的观测路径），而 BUG-0034 修复卡的回归防线复跑集
（m1_01/m1_02/m2_at01/m3_de01/m3_or04）不含 CFG02 ⇒ 自该重写起
CFG02 从未被复验，直到本卡独立跑通。
