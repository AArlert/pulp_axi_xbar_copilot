# KILL-0007 — third §12 self-injury proof (extends KILL-0006 to BUG-0072's quoted `$(...)` bypass)

## symptom

This is a self-injury (KILL) proof record, not a defect report — see
`workflow/bugs.md` "KILL rows are self-tests, not defects" and
`doc/design-prompt/doc_mechanization.md` C12.4. It exercises
`scripts/docsx.py`'s `exec_gate` (§12 executor safety gate) with a third
adversarial `check=`-shaped input and proves it is rejected — before any
`subprocess.run` call happens — extending KILL-0006's original two proofs
(`doc/archive/bugs-archive.md`) with the shape BUG-0072 found bypassing the
gate: a denylisted word wrapped in a QUOTED `$(...)` command substitution.
Pre-fix, `docsx.exec_gate('test "$(cat doc/bugs.md; rm -rf sim/out)" = "x"')`
returned `(True, '')` — the injected `rm -rf sim/out` would have reached
`subprocess.run(["sh", "-c", cmd])` for real.

## rca

```
observed:   pre-fix, docsx.exec_gate('test "$(cat doc/bugs.md; rm -rf
            sim/out)" = "x"') -> (True, '') — the injected rm would have
            reached subprocess.run.
anomaly:    shlex(posix=True) hands exec_gate a QUOTED $(...) substring as
            one opaque token; the old gate only did `tok in DENY_SIMPLE`
            (exact-string membership) plus a first-token-of-segment
            allowlist check — neither looks *inside* a token's content.
chain:      quoted $(...)/backtick/${...} content never scanned -> the
            denylisted word inside it is invisible to both defense layers
            -> exec_gate returns (True, '') -> would reach
            subprocess.run(["sh", "-c", cmd]) for real (sh evaluates the
            substitution regardless of the outer quoting style).
class:      TB_BUG (BUG-0072's own class) — a gap in the token-identity
            comparison strategy, not a data gap (adding words to
            DENY_SIMPLE alone cannot fix this).
guard:      this KILL row + scripts/tests/test_docsx.py::
            TestExecutorKillSelfInjury::
            test_kill_c_quoted_command_substitution_rejected_and_zero_subprocess_calls
            + 6 red/green TestExecutorGate cases + `python3 scripts/docsx.py
            --kill-proof`'s `[KILL-C]` line, all replayed by `make
            selftest`/`make check`.
```

## fix

commit: registered by BUG-0072's own `fix_commit` column (orch backfills
the sha there on closure); this page is the self-injury re-proof record,
not the fix record itself.
what: `scripts/docsx.py`'s `exec_gate` now (a) rejects any command
containing `$(`, a backtick, or `${` outright, anywhere in the raw command
text, before tokenizing even happens; and (b) replaced the
`tok in DENY_SIMPLE` exact-membership scan with a word-boundary *content*
scan (`_deny_hit_in_token`) so a denylisted word hiding inside a quoted
token — with or without a substitution — is caught too.
