# BUG-0012 — ATOP 原子读引发读通道额外假冲突 stall，spec.md 未蒸馏该交互

> 状态：OPEN（SPEC_ISSUE，观察性，非阻塞，待 rev 仲裁）。本页为 in-progress
> 详情页——`fix`/`rerun`/`regression_guard` 三段在仲裁前如实留白/记待办，非编造。
> 本页只陈述症状/事实，**不预判裁决结果与条款落点**（裁决权属 rev）。

## symptom

`vendor/axi/doc/axi_demux.md` §Atomic Transactions→Implementation 记载：原子读
（atomic load）事务的 ID 被 AW 通道「注入」到 AR 方向的 ID 计数器以防其下溢，
并明确「atomic loads can lead to additional false conflict stalls on the read
channel」。换言之，一笔原子读可能使**同一 slave 端口**上另一笔低位 ID 相同、
目标不同 master 端口的**普通读**落入 §5.2.1 的保序 stall——这是一次由**写方向
事件（ATOP AW）**引发的**读方向 stall**，不落在 spec.md §5.2.1 现有「同 ID 且
**同方向**、目标不同 master 端口」的字面框架内。

spec.md §5.2 与 §6 均未收录此跨方向交互。风险：M2-AT01 场景若在仿真中撞见此
现象（原子读与同低位 ID 普通读在飞重叠时读通道出现"意外" stall），在未登记该
条款前可能被误判为 DUT_BUG。

## first_anomaly

非仿真发现（静态阅读许可来源，未跑仿真）。M2 ATOP 场景（testplan M2-AT01）
规划时通读 `vendor/axi/doc/axi_demux.md` §Atomic Transactions→Implementation，
读到「As only a part of the AXI ID is compared ... atomic loads can lead to
additional false conflict stalls on the read channel」一句；回查 spec.md 发现：
- §5.2.1 只描述"同 ID **同方向**目标不同 master 端口"的 stall；
- §6（ATOP）只述 atomic load 需 B∧R 成对响应 + ID 唯一性约束，未提该 stall
  副作用。

即该交互在上游文档明载、而 spec.md 尚未蒸馏，即本条。

## taxonomy

SPEC_ISSUE

许可来源（axi_demux.md）明文描述了一个外部可观测的行为交互，spec.md 尚未把它
蒸馏成条款——属"spec 未覆盖某已文档化行为"的 SPEC_ISSUE（观察性：来源完整
可溯，非来源冲突、非来源缺失）。非 DUT_BUG（该 stall 是上游文档明述的正常
行为，非违规；且无任何波形/证据）、非 TB_BUG、非 TOOL_ENV。

## rca

1. spec.md §5.2.1 蒸馏自 xbar.md §Ordering and Stalls，其框架是"同 ID + **同
   方向** + 目标不同 master 端口 → stall"。
2. ATOP 的读写通道耦合是 AXI4 本身不存在、由 AXI5 原子操作引入的额外依赖
   （demux.md §Atomic Transactions）：为防 AR 计数器在原子读的"无对应 AR 的 R
   beat"上下溢，AW 把原子读 ID 注入 AR 计数器。
3. 该注入使 AR 计数器"看见"一个并非来自真实 AR 的占用，于是同低位 ID 的真实
   普通读可能被判为"同 ID 已在飞、目标不同"而 stall——一次写事件触发的读方向
   stall，超出 §5.2.1 的同方向字面框架。
4. spec.md 蒸馏 §5.2/§6 时未把 demux.md 这一相邻段落的跨方向副作用并入，于是
   该交互无 spec 条款可依，M2-AT01 判读时缺期望值来源。

## fix

**REV-005 仲裁裁决（2026-07-27）：SPEC_CHANGED —— 蒸馏为派生条款，非阻塞。**

rev 独立核验 demux.md L83-87（§Atomic Transactions→Implementation）原文：AW
**"'inject' the ID of an atomic load to the ID counter of the AR channel"** 防
下溢；**"As only a part of the AXI ID is compared ... atomic loads can lead to
additional false conflict stalls on the read channel"**，且明述为正常、非退化
行为。spec §5.2/§6 均未收录。**来源完整**（非缺失、非冲突）。

**裁决**：SPEC_CHANGED——把该已文档化的外部可观测交互蒸馏为 spec 派生条款。
不蒸馏则 M2-AT01 若撞见该 stall 会缺期望值来源、可能被误判 DUT_BUG。
- **条款落点**：归入 **§6（ATOP）作副作用派生条款**，并在 **§5.2 加交叉引用**
  （因其超出 §5.2.1"仅同方向"字面框架：一次写事件 ATOP AW 引发的读方向 stall）。
- **非阻塞**：M2-AT01 **核心判据**（B∧R 成对 §6.3、ID 唯一 §6.4）不受影响、照常
  落地产证据；本条仅关"额外读 stall"旁证观察的判读口径。

**orch 应用范围**（rev 只出裁决，spec 编辑 + 重 pin + 本 bug 状态转 SPEC_CHANGED
由 orch）：§6 增派生条款 + §5.2 交叉引用；依据栏记 demux.md §Atomic
Transactions→Implementation（L83-87）。详见 `doc/review/REV-005.md` §3。
