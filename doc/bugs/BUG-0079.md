# BUG-0079 — M5-RN02"探及连通域边界"must-reach 结构性未兑现（随机轮固定偏移只探区间内部）

## symptom

testplan M5-RN02 行 must-reach 声明"随机地址角落分布须真正探及连通域边界
（非只探中心地址）"，该行已 ✅。但修复前 `xbar_soak_cfgd_seq` 的全部地址
构造（round 0 peak `0x0010_0000`/`0x0020_0000`、sweep `0x0040_0000+`、随机轮
`0x0030_0000 + r*0x1_0000`）均为区间内部固定偏移——任何种子下都不可能触达
region 的 `start_addr`（含）或 `end_addr-8`（不含终址前最后一拍），声称
结构性（种子无关）未兑现。且 `functional_coverage.sv` 无量化该子句的
coverpoint，证据摘录层无从判断（收口审计判"无法从现有证据判断"，源码走查
定性为结构性缺口）。

## first_anomaly

signal: `xbar_soak_cfgd_seq` 各 addr_base 常量 vs testplan RN02 行 must-reach 子句
time: n/a（源码静态走查）
how_found: M5 收口审计证据链核查（0.5.15）发现证据不含该数据 → 源码走查
确认结构性不可达。rev 收口评审（0.6.0 前）指出本缺口与 BUG-0076/0077/0078
同类（must-reach 结构性未兑现即翻绿），按"失败无条件登记"纪律补登本号。

## repro

修复前任意 `make run TEST=m5_rn02_soak_test SEED=<n>`：静态检视
`tb/seq_lib.sv` cfgd 序列地址常量即可证实无边界触达路径（种子无关）。

## taxonomy

TB_BUG——激励与场景行自身 must-reach 声明不符（与 BUG-0077/0078 同型）。

## fix

`tb/seq_lib.sv` `xbar_soak_cfgd_seq::body()` 增加确定性连通域边界探针
（每个 rule-reachable 连通端口各一笔 `start_addr` 低边界写 + 一笔
`end_addr-8` 高边界写，spec §3.2 含起不含终语义；§8.3 构造性落在连通域
内）。每种子必达，走 RN01 同款"构造性保证"惯例（无需新增 coverpoint 即可
判定到达——确定性构造 + 判决零失配即证）。

## reverify

修复后 `make run TEST=m5_rn02_soak_test SEED=1` PASS（边界笔计入
scoreboard 路由/数据判决，零失配）；`make regress` 241/241 PASS（RN02
×3 种子）。evidence 列由 `make evidence` 回填。
