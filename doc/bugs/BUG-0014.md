# BUG-0014 — `make lint` 缺 `-assert svaext`，vendor 文件编译期报错

## symptom

`sim/Makefile` 的 `lint:` 目标自行拼接 VCS 编译旗标（未复用
`scripts/make/vcs-2018.mk` 的 `VCS_FLAGS_2018`），缺失其中的
`-assert svaext`（该 vcs-2018.mk 头注释已载明其必要性："required for
elaboration system tasks"）。`make lint` 解析到
`vendor/common_cells/src/clk_int_div.sv:111` 的 elaboration system task 用法
即报 `Error-[SE] Syntax error ... Using elaboration system tasks requires
option -assert svaext`，编译在到达 `../tb/` 范围前即整体中止，`lint:` 目标
自身的"仅 `../tb/` 范围判定失败"过滤逻辑从未被执行到。

## first_anomaly

signal: n/a（工具链编译期报错，非仿真信号）
time: n/a
how_found: 本卡（M2-OR01/OR02）交付前按常规习惯跑 `make lint` 核对新增/
改动的 `tb/` 文件；该命令对本仓库任何改动都会以同样方式失败（复现不需要
本卡的任何代码改动，见 rca）。

## taxonomy

TOOL_ENV

## rca

1. `scripts/make/vcs-2018.mk` 定义 `VCS_FLAGS_2018`，包含 `-assert svaext`
   （该文件头注释："required for elaboration system tasks"）,被 `compile`/
   `run` 目标使用。
2. `sim/Makefile` 的 `lint:` 目标未复用 `VCS_FLAGS_2018`，而是手写了一份独立
   的旗标列表（`-full64 -sverilog -timescale=1ns/1ps -ntb_opts uvm-1.2
   +vcs+lic+wait $(LD_FIX) +lint=all,noVCDE`），遗漏了 `-assert svaext`。
3. `vendor/common_cells/src/clk_int_div.sv`（`vendor.f` 首批文件之一，先于
   `dut.f`/`tb.f` 解析）使用了需要该旗标的 elaboration system task，无此
   旗标时 VCS 直接报 `Error-[SE]` 并中止整个编译。
4. 因编译在 vendor 阶段即中止，`lint:` 目标自身"only ../tb/ 范围内失败才
   判本仓库不合格"的 grep 过滤逻辑从未有机会执行——`make lint` 对本仓库当前
   任何版本都会以同一签名失败，与被测改动内容无关。

## fix

commit: 占位——由 orch 收版后回填。
what: `sim/Makefile` `lint:` 目标改为复用 `$(VCS_FLAGS_2018)`（含
`-assert svaext`），不再手写第二份旗标列表；未额外剥离
`-debug_access+all -kdb`（实测不影响 lint 判定，保留以减少与
compile:/run: 的旗标漂移面）。修复本条时同批发现并修复了独立的第二个
阻断点（`lint:` 缺 `-top $(TOP)`），已登记为 BUG-0019，见该条 ## fix。

## rerun

`make lint`（默认 `TEST=upstream_sanity`，`FLISTS` 走 `vendor.f+dut.f+
tb_upstream.f`）：`vendor/common_cells/src/clk_int_div.sv` 不再触发
`Error-[SE]`——本条症状消失，编译干净通过 elaboration（0 error/0
warning），到达并执行 `../tb/` grep 过滤逻辑，输出 `lint clean within
../tb/ scope`（该 flist 分支本不含 `../tb/` 文件，属预期真阴性）。
`make lint TEST=m2_cfg01_reconfig_test`（`FLISTS` 走 `tb.f`，真含
`../tb/` 文件）：同样 0 error 通过 elaboration，过滤逻辑随即在真实
`../tb/` 范围内命中若干既有 `Lint-[SVA-UA]`/`Lint-[NS]`/`Lint-[WMIA-L]`/
`Lint-[SVA-AECASR]`/`Lint-[SVA-CE]`/`Lint-[SVA-DIU]`/`Lint-[SVA-NSVU]`/
`Lint-[SV-PIU]`/`Lint-[ULCO]` 类告警（分布于 `tb/*.sv` 与 `tb/sva/*.sv`，
共约 190 处命中，多为同一行的模板重复计数）——这些告警与本条修复内容
无关（本条只解锁了 lint 得以真正执行的能力，不改变判据范围也不修
tb/ 代码），如实登记但不在本条内处理，交由 orch 分诊是否另开卡。
主链路回归：`make run TEST=m2_cfg01_reconfig_test SEED=1`、
`make run TEST=m1_01_smoke_test SEED=1` 均 PASS（`UVM_ERROR: 0`，
`Summary: 2143 assertions, 870 with attempts, 0 with failures`），确认
`lint:` 目标改动未波及 `compile:`/`run:` 主链路。
