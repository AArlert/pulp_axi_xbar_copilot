# BUG-0025 — 译码未命中的事务不入跟踪表，其完成不参与乱序检查（漏检）

## symptom

`tb/sva/axi_xbar_stall_sva.sv` 的跟踪表登记条件带 `aw_hit` / `ar_hit`
（地址译码命中某个 master 端口）：

```systemverilog
if (aw_valid && aw_ready && aw_hit) begin   // aw_hit==0 的事务不入表
  w_id_tgt[aw_id] <= aw_tgt; ...
end
```

译码未命中的事务（走 default port 或 error slave）因此从不进入在飞集合。
当它的 B/R 完成返回时，该完成**不参与任何乱序检查**。

~~当它的 B/R 完成返回时，`w_id_seq[b_id]` 为 X ⇒ 与其它候选的序号比较恒假。
安全但漏检：不会假红（X 比较恒假 ⇒ 不触发断言）。~~

> **订正 (i)（REV-011 §5.2(ii)，2026-07-28）：「读到 X ⇒ 比较恒假 ⇒ 安全」
> 这条安全性论证不成立。**
> `w_id_seq`/`r_id_seq` 是 `int unsigned`——**2-state**，缺省为 **0** 而非 X。
> 更要紧的是：若该完整 ID **曾登记过**，读到的是**陈旧**的非零 seq/tgt
> （reset 只清 `*_id_open`，见 `stall_sva.sv:120-127`），而 `w_reorder()`
> **不检查完成侧自身的 open 位** ⇒ 陈旧值会继续参与比较，**可产生无来源
> 假红**。即本条同样是双向误差，不是纯漏检。
> 这正是 spec §5.2.6 第 3 条要成文的原因：「不断言」必须写成显式的、引条款的
> 排除并配非判决 cover，**不得**靠"未登记 ⇒ 读默认值 ⇒ 比较恰好为假"达成
> ——那在报告上与"忘了写"完全同形（REV-011 §4 G1，与 BUG-0022 lint 假绿、
> BUG-0028 分母缩水同一失效家族：**沉默的通过**）。

本该被检出的"error slave 响应越过更老的正常响应"这类乱序会静默通过——其中
**哪些维度该被检出、哪些不可断言**已由 spec §5.2.6 定案，见 `## regression_guard`。

## rca

1. 跟踪表的登记条件要求译码命中（`aw_hit`），意图是"只跟踪有明确目标
   master 端口的事务"——因为 §5.2.1 的判据需要比较目标端口。
2. 但注销条件（B/R 握手）**不带**对称的过滤：任何完成都会去查表。
3. ~~未登记事务完成时读到的是未初始化的 `w_id_seq`（X），后续的序号比较
   恒为假 ⇒ 静默跳过。~~ **订正（REV-011 §5.2(ii)）**：`w_id_seq` 是
   `int unsigned`（2-state），缺省为 **0** 而非 X；若该完整 ID 曾登记过则读到
   **陈旧**的非零值（reset 只清 `*_id_open`，`stall_sva.sv:120-127`），且
   `w_reorder()` 不检查完成侧自身的 open 位 ⇒ 陈旧值继续参与比较，**可产生
   无来源假红**。原第 3 点的"恒假 ⇒ 安全"论证作废，详见 `## symptom` 订正 (i)。
4. 净效果：译码未命中的那一类事务对乱序检查不可见（漏检），**且**曾登记过的
   完整 ID 会带着陈旧目标/序号继续参与他人的比较（假红）——双向误差。

### 范围订正（REV-010 §3.4，2026-07-28——**本页原 rca 低估了缺陷范围**）

rev 亲读 `tb/sva/axi_xbar_stall_sva.sv:99-100`：

```systemverilog
always_comb aw_hit = decode_mst_port(aw_addr, ADDR_MAP, 1'b0, '0, aw_tgt);
```

`en_default` 参数被**硬编码为 `1'b0`**。故被跟踪表丢弃的**不止 error slave
流量**，还包括 spec §3.3.2 定义的 **default master port 路由流量**。二者的
spec 地位不同，**必须拆开处置**：

- **default port 半边 = 纯 TB_BUG，无需仲裁**：default master port 是一个真实的
  master 端口（spec §3.3.1/§3.3.2），§5.2.1 的「目标为不同 master 端口」对它
  直接适用。跟踪表把它当「未命中」丢弃是实现与 spec 不符，改法明确。
- **error slave 半边 = 真 SPEC_ISSUE，须先仲裁**：§5.2.1 以「master 端口」为
  约束单位，而 §4.1 的 per-port `axi_err_slv` **不是**外部 master 端口；§4.5 只给了
  「响应 ID/握手遵循 AXI4 一般规则」。即 spec 对「error slave 的响应能否越过同 ID、
  同方向、目标为正常 master 端口的更老响应」**未作定义**——taxonomy `SPEC_ISSUE`
  的教科书签名。按 `workflow/discipline.md` rule 1，DV 不得自行取舍。

## arbitration (REV-011)

仲裁完毕；行状态 OPEN → `ACCEPTED@M3`。全文见 `doc/review/REV-011.md` §1。**

### 裁决（三层，逐层给许可来源）

1. **default master port 半边 —— 不存在 spec 缺口，§5.2 直接适用。**
   xbar.md L35 原文 "any address … is routed to **the default master port**
   instead of the decode error slave"；spec §3.3.2 同述；§2.3 的
   `default_mst_port_i` 取值即 master 端口索引。⇒ §5.2.1 的"目标为不同 master
   端口"对它字面适用。**纯 TB_BUG，无需仲裁**（维持 REV-010 §3.4 这一半）。

2. **完整 ID 维度 —— 可断言。本页/REV-010 §3.4 判"未定义"，本卡不同意。**
   crossbar 的 slave 端口本身是一个 AXI4 slave 接口（spec §1、xbar.md §开篇：
   实现完整 AXI4）；许可来源自己写出了那条"一般规则"——xbar.md L86:
   "AXI transactions with the same ID and direction **must remain ordered**"；
   §4.5 又把 err_slv 的响应显式拉回 AXI4 一般规则（是纳入，不是排除）。该义务
   只依赖**接口**，不依赖内部路由。
   ⇒ **同一 slave 端口上完整 ID 相同、同方向的两笔事务，其 B/rlast 完成序须与
   接受序一致——无论它被路由到 master 端口、default master port 还是内部
   err_slv。** checker 必须把译码未命中事务纳入这一维度（今天整条丢弃 = 漏检）。

3. **低位 ID 桶维度（完整 ID 不同、其一走 err_slv）—— 确属未定义，不可断言。**
   §5.2.1/§5.2.2 的桶级约束以"不同 **master 端口**"为条件；§4.1 与 xbar.md L33
   把 err_slv 定为"每 slave 端口**内部的**模块"；demux.md §Ordering and Stalls
   （L54-76）与 mux.md 对 err_slv **一字未提**（本卡 grep 空集）。而 AXI4 对
   不同 ID 之间不设次序义务，第 2 层的兜底在此不成立。
   ⇒ taxonomy `SPEC_ISSUE`（"does not define the behavior at all"）成立，
   **但处置是"不断言"而非"等待答案"**：无来源的断言会在 M3 错误路径场景假红，
   即 BUG-0013/REV-006 已付过学费的形状。须显式排除 + 非判决 cover + 列上游
   确认项（不阻塞里程碑）。

**条款提案（rev 只出提案，orch 应用并重 pin）**：P-REV011-1 = 新增 spec §5.2
第 6 条；P-REV011-2 = §4 新增第 6 条交叉指针。提案全文与许可来源清单见
`doc/review/REV-011.md` §1.3。**本卡未编辑 `doc/spec.md`。**

2. **`## symptom` 称未登记事务完成时 `w_id_seq` 为 X ⇒ 比较恒假——错，且

   （`tb/sva/axi_xbar_stall_sva.sv:120-127`），且 `w_reorder()` **不检查完成侧

   **无来源假红**。这正是提案 P-REV011-1 第 3 条（"排除必须显式并引条款，
   不得靠默认值/陈旧值让比较恰好为假"）要成文的原因。
