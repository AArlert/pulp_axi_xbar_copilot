# BUG-0062 — REV-035 裁决论证内两处事实陈述失实（"lzc 无 always 块" + CW-010 §Q1(i)）

## symptom

`doc/review/REV-035.md` 的裁决论证里有两处经不起回源核对的事实陈述，其一被用作
"必须重写而非删句"的理由：

- **(F2，实质)** REV-035 §0 行 F、§Q2(a).2、§Q2(d) 硬警告 2 三处称 `lzc.sv`
  "无一个 `always` 块 / lzc 无 `always` 块（亲读）"。实测 `grep -c always
  vendor/common_cells/src/lzc.sv` = **1**（`:56 always_comb begin : flip_vector`）
  ——陈述失实。其**结论仍正确**（脚注 3 的"过程块"预设确不成立），但**理由必须换**。
- **(F1，无损)** §Q1(i) 称 CW-010"论证列现把 `fifo_v3.sv:122` 并列在 Cond 项里"
  ——CW-010 的 `:122` 自带 `Branch IF-117` 限定括注，"Cond 项"归属其后并列的
  `spill_register_flushable.sv:78/79/84/85`，该列**原本即自洽**。

发现路径：BUG-0050/0051 的 arch fixer 在按卡内"每个数字自己回源、不得照抄"要求
执行时发现并拒绝照抄——是隔离链（"不得照抄裁决"这条卡内纪律）起作用的直接证据。

`:54 if (MODE) begin : g_flip` 内，本闭包两个 `lzc` 实例（`rr_arb_tree.sv:202-205`

未统计"。该重写成因 `M4-coverage-final-sweep.md` §10.2(A) 已落地并经独立复核成立。
