# BUG-0007 — M1-01 SVA 挂接机制偏离：`bind` 进 interface 被 VCS-2018 拒绝，改直接例化

## symptom

`doc/design-prompt/sva_bind.md` C1.1（rev-gated，REV-002 放行时的原始措辞）
与 CLAUDE.md §6 均要求协议/时序 SVA 经 SystemVerilog `bind` 挂接到
`slvport_if`/`mstport_if` 每端口实例。按此机制编译 `tb/sva/axi_chan_sva.sv`
时，VCS-2018.09-SP2 在 elaboration 期拒绝，报：

```
Error-[IIM] Illegal instantiation of module
  Instantiation of module 'axi_chan_sva' is illegal.
  Interface "<slvport_if|mstport_if>" has a module instantiation which is
  not allowed.
```

即"module 直接 `bind` 进 interface 作用域"不被本工具链接受，非某处笔误。

## first_anomaly

signal: n/a（编译期 elaboration 失败，未进入仿真，无波形）
location: `tb/sva/axi_chan_sva.sv`（SVA 模块本体）经 `bind <slvport_if|
mstport_if> axi_chan_sva (...)` 挂接语句触发（该 `bind` 语句本身在此偏离
落地后已不存在于交付树——现场重放需按 REV-003 §2.1 的独立最小探针复现，
见下）
how_found: 本卡（M1-01 SVA 挂接实现）编译期实测触发 `Error-[IIM]`（原始
一手报错记录于 `tb/sva_bind.sv`、`tb/sva/axi_chan_sva.sv` 头注释）；REV-003
用与 `scripts/make/vcs-2018.mk` 完全同源的编译旗标（`-full64 -sverilog
-timescale=1ns/1ps -assert svaext -debug_access+all -kdb +vcs+lic+wait` +
`--no-as-needed` LDFLAGS + novas PLI）构造独立最小探针（interface + 独立
module + `bind <interface> <module>`）复现，报错签名逐字一致——不是靠
revert 本项目树重放，而是独立探针复现，避免"复现原始失败"与"验证修复"
共享同一份可能已被修复代码污染的编译输入。

## rca

1. `doc/design-prompt/sva_bind.md` C1.1（REV-002 放行时的原始措辞）与
   CLAUDE.md §6 均按上游/框架惯例约定协议 SVA 经 `bind` 挂接到每个
   slave/master 端口 interface 实例（`slvport_if`/`mstport_if`）。
2. VCS-2018.09-SP2 的 elaboration 期不接受"module 直接 `bind` 进 interface
   作用域"这一形态，一律判 `Error-[IIM]`——REV-003 §2.1 用与项目编译旗标
   同源的独立最小探针复现，确认为工具能力边界，非本项目 `axi_chan_sva.sv`
   内容或挂接坐标写法错误。
3. 因此 `tb/sva_bind.sv` 改为在 `tb_top.sv` 自身的 `slv_if`/`mst_if` 例化
   generate 循环之后，直接例化 `axi_chan_sva`（`` `include``-d 进
   `tb_top.sv`），而非 `bind`。`axi_chan_sva` 模块本体未改：其 `interface
   axi` 泛型端口仍只读 `slvport_if`/`mstport_if` 上与 DUT 经
   `` `AXI_ASSIGN_TO_REQ``/`` `AXI_ASSIGN_FROM_RESP`` 接线的外部可见 AXI4
   通道信号，不穿透读取 DUT-internal 信号——REV-003 §2.2 结构核验确认
   `bind` 与直接例化对同一 module body 是等价的纯连接语法差异，不改变
   C2.1-C2.5 断言的文本、触发条件或 `disable iff` 语义。
4. 该偏离在代码内以头注释形式主动披露（`tb/sva_bind.sv`、
   `tb/sva/axi_chan_sva.sv` 开篇），未静默吞掉；但未同步登记
   `doc/bugs.md` 行——本条即补齐该登记（TOOL_ENV 五类之一，CLAUDE.md §2
   登记规则：不论是否已在同卡内修复，均需成行）。

与 seed/stimulus 无关的编译期确定性错误；同 `BUG-0001`（genvar 内
`$sformatf` 常量折叠）、`BUG-0006`（另一处 VCS-2018 O-2018 生成期限制）
一样，属已知工具（VCS-2018.09-SP2）能力边界，非 DUT `axi_xbar` 行为问题，
非本项目 checker 逻辑错误。

## fix

commit: 64d0780
what: `tb/sva/axi_chan_sva.sv` 保持独立模块、内容不变；挂接语句由
`bind <slvport_if|mstport_if> axi_chan_sva (...)` 改为 `tb/sva_bind.sv`
（`` `include``-d 进 `tb_top.sv`，位于 `slv_if`/`mst_if` 例化之后）中两个
`generate` 循环内的直接例化，每 slave 端口（6）/master 端口（8）各一份
实例，`ID_WIDTH` 按端口类分别传参（spec §5.1.1）；`doc/design-prompt/
sva_bind.md` C1.1 已同批订正措辞记录实际挂接机制（REV-003 §4）。断言集
（C2.1 握手稳定 / C2.2 复位空闲 / C2.3 LAST-vs-len / C2.4 禁固定拍数 /
C2.5 禁仲裁序）内容未变。
