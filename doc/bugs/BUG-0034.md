# BUG-0034 — atop 原子读 R 与同桶普通读 R 在 slave 端口 R 通道疑似 beat 交织

- **状态**: OPEN
- **suspect**: TB（DUT_BUG vs TB_BUG 未决，见下）
- **发现**: M3-AT02（配置点⑤落地卡，DV）构造 spec §6.5 跨方向假冲突时
- **严重度**: 中；本卡已用单拍构造绕过，M3-AT02 已转绿，不阻塞 M3

## 症状

M3-AT02 需在同一 slave 端口令一笔要求读响应的原子操作（`aw.atop` =
ATOMICLOAD，目标 mstB）与一笔**低 `AxiIdUsedSlvPorts=3` 位相同、完整 ID
不同、目标 mstA ≠ mstB** 的普通读在飞重叠，使 spec §6.5 所述影子 AR 假冲突
真实发生。

当两腿的读 burst 均为**多拍**（leg A read `AxLEN=3` → 4 拍）时，slave 端口
R 通道观测到破损，四路证据同时命中（单拍构造下全部为 0）：

- `tb/slvport_agent.sv:521` `MON_RNOAR` — R beat 找不到匹配的已接受
  AR/atomic-load AW。
- `tb/sva/axi_chan_sva.sv:252` `SVA_RLAST_LEN` — RLAST 落在错误 beat
  index（`RLAST beat index 2 != AxLEN 3`、`index 1 != AxLEN 0`）。这是
  bind 到通道接口的协议 SVA，**独立于 UVM monitor**。
- `tb/scoreboard_refmodel.sv:931` `SB_RBEATS` — 普通读 id 的 R beat 数被
  截短（`beat count 3 != 4`、`2 != 4`），另有游离 beat。
- `SB_ATOP_DANGLING` — atop 的 R 半永不返回（B seen=1, R seen=0），
  `SB_RESP_ROUTE`/`SB_RESP_DANGLING` 连锁。

## 排除 / 事实

- `r_ready` 全程恒 1（`tb/slvport_agent.sv:45` drive_idle，无 TB 反压）⇒
  非驱动侧背压致 R 停滞。
- 单拍腿（leg A/atop 均 `AxLEN=0`）下全部证据归零、场景干净转绿 ⇒ 破损
  仅在**多拍**时出现。
- xdebug `signal.changes` 亲测 `tb_top.slv_if[0].r_valid` 全程仅 2 次跳变
  （单一连续 valid 块），而 `r_id` 在该块内跳变 3 次 ⇒ 两个不同 ID 的多拍
  R burst 在**同一连续 valid 块内交织**的结构性证据。
- 多端口并发跑时（forked 6 端口）曾观测到 5/6 端口通过、仅 1 端口破损 ⇒
  破损是**时序巧合触达**（自然串行化时躲过，紧密重叠时命中）。

## 未决定性

AXI4（spec §1）**禁止读数据交织**。故：

- 若 DUT 的 slave 端口 R 通道确实把 atop 影子读 R 与同桶普通读 R 交织
  输出 ⇒ **DUT_BUG**（协议违反；且与 spec §6.5「只影响是否 stall、不影响
  功能正确性」矛盾）。
- 若 DUT 实际未交织，而是 UVM monitor（`tb/slvport_agent.sv:503-530`
  的 `r_busy` 到 `r_last` 不换 burst 的重建）与 `axi_chan_sva`（`:252`）
  在此角落重建/计数有缺口 ⇒ **TB_BUG**。

定性须对该 FSDB 逐 beat decode `r_id`/`r_last`/`r_valid`（本卡 `value.at`
在此 FSDB 上取值返回 unknown，未能逐 beat 落定，留待专卡用 xdebug
`axi.query`/逐沿采样或 Verdi 波形完成）。

## 本卡处置（合法绕过，缺口另账）

M3-AT02 改用**单拍**两腿（`tb/seq_lib.sv` `slvport_at02_seq`，leg A
`p.len = axi_pkg::len_t'(0)`）：单拍 burst 每 beat 即 r_last、无交织窗口，
§6.5 假冲突仍真实发生（`cg_atop_read_interaction.colliding_read_present`
命中、atop B+R 配对、路由/数据/响应零失配）——完整满足 testplan M3-AT02
三条判据。多拍腿的破损不是 M3-AT02 的判据要求，绕过合法。

不在判决本体上加临时补丁、不把观测行为抄成期望值（spec-from-RTL 红线）。
