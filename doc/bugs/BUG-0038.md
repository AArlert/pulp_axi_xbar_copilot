# BUG-0038 — spec §0#4 names addr_decode/axi_demux as mandatory coverage scope, but both are pass-through wrappers with no line/cond/branch/assert content of their own

## symptom
Per the clean baseline (17-test, single 6x8 design) `urg` report
(`doc/evidence/v0.4.0/M4-coverage-baseline.md` §3), the `addr_decode` and
`axi_demux` module pages report **blank** (not 0%, not N/A-but-scored —
literally no bins collected) for LINE, COND, BRANCH and ASSERT; only
TOGGLE is populated. Every other spec-§0#4-named module
(`axi_xbar_unmuxed`, `axi_mux`, `axi_err_slv`) reports all six types (or a
subset with a plausible reason, e.g. no FSM construct).
