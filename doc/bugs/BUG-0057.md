# BUG-0057 — `doc/evidence/v0.4.6/BUG-0040.log` 关闭证据首行不可重放、签名自印；`evidence.py` 无仓内可重放约束

## symptom

`doc/evidence/v0.4.6/BUG-0040.log`——一条已 CLOSED 缺陷的关闭证据首行不可重放，
且其签名是自印口令：首行 `CMD: bash /tmp/claude-1000/<repo>/292cdefc-…/scratchpad/
bug0040_verify.sh` 指向仓外 `/tmp` 路径（随该 session 结束/清理即消失，任何人无法
从仓库重放），第二行 `expect: BUG0040_VERIFIED_CLEAN` 是被执行脚本自身 `echo` 的
口令（任何以同样口令收尾的脚本都能伪造同一签名）。根因面：`scripts/evidence.py`
对 `--cmd`/`--expect` 的内容本身无任何约束——不检查命令是否在仓库内可重放，也不
检查签名是否来自被测门禁本身而非命令自印。详见 `doc/bugs.md` BUG-0057 行、
`doc/review/REV-037.md` §BUG-0057、`doc/review/REV-038.md` §C 行 0057、§B.4。

## fix

commit: 本卡（dv fixer·卡2c）落地；sha 由 orch closeout 回填。
what: `scripts/evidence.py` 的 `--cmd` 分支在跑任何命令、写任何证据文件之前，
新增对 CMD 文本中「解析到仓库根之外的绝对路径 token」的拒绝检查（正则
`CMD_ABS_PATH_RE`，跳过 URL scheme 与标识符内部片段；对每个候选 token 用
`Path(tok).resolve()` 核对是否落在 `CFG.root` 之内，不在则退出非零、零落盘）。
这是 REV-037 §BUG-0057 裁决"仓内可重放"半面的机械化实现；"EXPECT 须来自门禁而非
命令自印"半面按同一裁决**不建通用检测器**（写"防洗白检测器"是
`workflow/discipline.md` §2 点名的投机式过度设计），改走本页 `## regression_guard`
的 `type: checklist`。见 `doc/fw-feedback.md` FB-32（`scripts/evidence.py` 为
上游文件）。
